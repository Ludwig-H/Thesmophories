# Segmentation des pages du *Ravennas* (ff. 162v–177r)

> État : **en cours** (squelette ; sera complété à chaque étape).

## Objet

Préparer les images de R (Ravenne, Classense 429, ff. 162v–177r, 30 pages) pour
l'étude graphologique et la transcription : colonne du texte, lignes, blocs de
scholies marginales, découpes agrandies, recadrages du fac-similé.

## Plan

1. `outils/images/segmenter.py` — colonne, lignes, blocs marginaux → `ravennas/segmentation/fXXX.json`.
2. `outils/images/decouper.py` — découpes ×2 par ligne, tuiles des marges, planches contact → `.travail/decoupes/fXXX/`.
3. Contrôle visuel ; bornes de vers → `ravennas/segmentation/folios.tsv`.
4. Recadrages du fac-similé → `edition/images/fXXX.jpg` + `edition/images/recadrages.json`.
