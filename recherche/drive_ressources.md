# Ressources documentaires locales (`.sources/drive/`) — synthèse par usage

> **État : en cours de rédaction** (2026-10-25). Le fichier est complété section par section ; une section marquée *(à compléter)* n'est pas encore rédigée.

## 0. Conventions

- **Emplacement.** Tous les fichiers décrits ici sont dans `.sources/`, que git ignore (ouvrages sous droits : ne jamais les déplacer dans la partie versionnée). Abréviation : **`F/`** = `.sources/drive/fichiers/`. Les autres sous-dossiers (`.sources/drive/ravennas/`, `editions/`, `papyrus/`, `thesmophories/`, `textes/`, `textes_metrique/`) sont cités en entier.
- **Noms de fichiers.** Quand un nom est long ou porte des mentions parasites, il est abrégé par un motif shell : `*` remplace la fin ou le milieu du nom (ex. `F/Grec/Aristophane/Thesmophories/Le donne alle Tesmoforie*.pdf`). Mettre les chemins entre guillemets (espaces, apostrophes, `||`, `:`).
- **Interrogeable ?** **[T]** = couche texte présente (un `.txt` du même nom est à côté du PDF ; `grep` possible) ; **[T-]** = couche texte présente mais médiocre (OCR fautif, grec mal reconnu) ; **[I]** = image seule (OCR à faire, ou lecture sur l'image) ; **[S]** = source texte native (`.tex`, `.xml`, `.txt`).
- **Pages.** « p. » = pagination imprimée ; « p. PDF » = rang de la page dans le fichier.
- **Identification.** Chaque notice a été établie en ouvrant le fichier (page de titre, en-tête d'article, couche texte). Ce qui n'a pas pu être contrôlé est marqué **[à vérifier]**.
